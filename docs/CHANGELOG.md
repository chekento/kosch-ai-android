# KAL changelog / KAL-Changelog

English is listed first. The adaptive HTML version at [`changelog.html`](changelog.html) selects German or English from the browser language and defaults to English.

## 0.3.0-alpha01 · Unified Professional Shell

### Added

- A single KAL shell: Home, Apps, Workspace, AI News, Tools, Pen Space and Settings.
- Local Command Center with explicit hand-off for browser, phone, camera, files and other system surfaces.
- Persistent Workspace pages, page manager, app/folder placement and arrange mode.
- AI News source hub with 23 named research, product, governance and security sources.
- Five UI previews, a KAL app icon, an APK download card and three product banners.
- Browser-language adaptive English/German documentation portal; English is the default.

### Safety / boundary

- Offline APK remains free of `INTERNET` and `RECORD_AUDIO` permissions.
- Assistant and screen/camera awareness remain opt-in and disabled by default.
- External links open consciously in the browser.
- This is a test snapshot, not beta and not a production release.
