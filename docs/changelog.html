0.3.0-alpha01 · Unified Professional Shell

Added

  • Unified KAL shell with Home, Apps, Workspace, AI News, Tools, Pen Space and Settings.
  • Command Center with local actions and clear external hand-offs.
  • Workspace pages, page manager, app/folder placement and explicit arrange route.
  • AI News source hub with 23 named research, product, governance and security sources.
  • Five documented UI previews, app icon, APK card and three launch banners.
  • English/German adaptive documentation portal; English is the default.

Safety / boundaries

  • Offline-first APK stays free of INTERNET and RECORD_AUDIO permissions.
  • Assistant and screen/camera awareness remain opt-in and off by default.
  • External news links open in the browser only after a visible user action.
  • This is a test snapshot, not a beta and not a production release.

Previous history

Earlier M2.5/M2.6 work remains documented in the repository's technical notes. The installable archive is maintained on the Versions page.
